# 📚 Library Management System (SQL Project)

## 📖 Project Overview

The Library Management System is a SQL-based database project developed using MySQL. It is designed to manage library operations such as maintaining books, authors, members, categories, and book issue records. The project demonstrates the implementation of relational database concepts and SQL queries.

## 🚀 Features

* Create and manage library database
* Store book and author information
* Manage library members
* Organize books into categories
* Record book issue and return details
* Perform basic and advanced SQL queries
* Create SQL Views for simplified reporting
